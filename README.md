## 真实评价和几个坑

Mac 应用测评和 Reddit 的 macOS 板块里，DaisyDisk 出现的频率很高，提到它的时候基本是推荐语气，最常见的说法是“清磁盘第一个想到它”“环形图比列表直观太多”。抱怨集中在几处：价格相对于“一年可能只用两次”的人偏高；拖拽删除的操作方式需要适应一两分钟；扫描整块大盘要等一会儿，尤其是机械硬盘或者装满小文件的目录。

具体到使用，有几个坑值得提前知道。

**完全磁盘访问权限不是可选项。** 没有这个权限，DaisyDisk 扫不到系统保护的目录，你会看到一堆“无法读取”，然后误以为磁盘没那么满。第一次打开时按提示去系统设置里授权，授完重启一次应用。

**App Store 版的权限限制是真的。** 上面提过，沙盒会挡住一部分路径。如果你买的是 App Store 版又发现扫不全，不是你操作错了。

**删除是不可逆的。** 收集器里确认之后文件就没了，不进废纸篓。删之前把路径看清楚，尤其是那些名字相似的项目缓存目录。

**它不告诉你该不该删。** 工具只负责显示大小，判断哪些是缓存可以重建、哪些是项目源文件，得你自己来。第一次用容易手滑删掉正在用的东西。

**退款看商店条款。** 数字软件的退款政策各家不同，有的给几天冷静期，有的售出不退。下单前在页面底部或者帮助中心确认一次，别等出问题才找。
